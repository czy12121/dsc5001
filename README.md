# DSC5001 奥斯汀动物收容所项目交接

本项目用猫狗入所时的信息，预测本次入所后 30 天内被奥斯汀动物收容所登记为领养的概率。这里收录了原表、清洗后的数据、试跑与正式实验、逐条预测、图表和组内报告。

## 从哪里看起

1. [组内实验报告 PDF](output/pdf/DSC5001_组内实验报告/DSC5001_奥斯汀收容所实验报告.pdf) 按最新顺序讲模型比较、连续年龄与年龄档的对照、A/B 特征组消融、树模型比较和幼猫错例。需要编辑时打开[同版 Markdown](output/pdf/DSC5001_组内实验报告/DSC5001_奥斯汀收容所实验报告.md)。
2. [实验计划和结果记录](奥斯汀动物收容所/DSC5001实验计划.md) 有建表规则、模型设置和正式结果。[侧会话备忘](奥斯汀动物收容所/DSC5001_侧会话备忘.txt) 记录了早期讨论和补充对照。最新的报告顺序见第 1 项。
3. 课程资料包括 [5001 项目要求](<5001/group project/Project.pdf>)、[5001 课堂项目说明摘要](output/pdf/DSC5001_课堂项目说明_转录与注意事项.pdf)、[课堂原始转录](<5001/group project/期中答案与课程项目安排说明.txt>) 和 [5002 作业要求](<5002/group project/要求.txt>)。

## 数据与 5002 的衔接

| 文件或目录 | 内容 |
|---|---|
| [原始数据](奥斯汀动物收容所/data/full/) | 奥斯汀市开放数据历史快照，173,812 条入所和 173,775 条离所记录，覆盖 2013 至 2025 年 |
| [2022–2024 年猫狗入所配对表](奥斯汀动物收容所/data/prepared/猫狗入所配对表_2022–2024.csv) | 33,089 次入所事件。包含物种、年龄、入所原因和状况、离所去向、距离所天数、30 与 60 天领养标签及配对状态 |
| [数据质检与样本量](奥斯汀动物收容所/data/prepared/) | 配对核查、时间划分、可用样本和正例数 |
| [早期试跑数据及来源记录](奥斯汀动物收容所/data/) | 2024 年 1–7 月猫狗试跑的入所、离所 JSON，以及来源记录 |

如果 5002 沿用同一主题，可以从配对表查看不同年龄、物种、入所原因和月份的离所去向及领养时间，也可以从原表选更长的时间范围。配对表中的 split 和 seen_in_earlier_split 是 5001 的预测实验标记。5002 做描述性分析时，可以按自己的研究问题确定时间范围、纳入条件和每张图所用的样本数。

奥斯汀市官方数据页：[Animal Center Intakes](https://data.austintexas.gov/d/wter-evkm) · [Animal Center Outcomes](https://data.austintexas.gov/d/9t4d-g238)。

## 在 Windows 上复现实验

直接浏览报告和结果即可查看已保存的实验。复跑时，在文件资源管理器中打开交接文件夹，在地址栏输入 powershell 并回车，然后运行以下命令。项目使用 Python 3.13.13，相关软件版本见 [requirements.txt](requirements.txt)。

~~~powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
cd .\奥斯汀动物收容所
..\.venv\Scripts\python.exe .\5001_正式数据准备.py
..\.venv\Scripts\python.exe .\5001_正式实验.py validate
..\.venv\Scripts\python.exe .\5001_正式实验.py test
..\.venv\Scripts\python.exe .\5001_混合数据核回归试跑.py
..\.venv\Scripts\python.exe .\5001_正式实验结果图.py
~~~

数据准备和实验脚本会重新生成配对表与输出。若要同时保留这里的已保存结果，可以复制一份项目后在副本里复跑。
